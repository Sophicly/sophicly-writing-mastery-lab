# Mark Scheme Assessment Bank — Never Let Me Go

Deterministic, code-scored MARK-SCHEME-LITERACY assessment bank (parsed by `SWML_Quiz_Bank::pick_session_msa`).
Examiner-level — harder + more precise than the Mark Scheme Quiz drill. Every question makes the
student JUDGE real writing about Never Let Me Go against the EXACT mark-scheme descriptor wording, and
forces them to USE the mark scheme's own vocabulary rather than a simplified paraphrase. Keys + feedback
live server-side and are stripped before questions reach the client. The AI is never the scorekeeper.

AOs tagged per question for stratified random selection (the picker spreads the questions across each board's own AO split).
Question types: MCQ · Select All · Fill · Ranking. Boards differ: AQA Modern Text = AO1+AO2+AO3 (+AO4 SPaG);
Edexcel GCSE Post-1914 = AO1+AO3 (no AO2, +AO4 SPaG on a separate grid); Eduqas Post-1914 = AO1+AO2 (+AO4 SPaG, AO3 not assessed in this section);
OCR J352 = AO1+AO2+AO3 in part (a) / AO1+AO2 holistic in part (b); Cambridge IGCSE 0475 = AO1+AO2+AO3+AO4, where AO4 is Personal Response, NOT SPaG.

### **SECTION A: AQA (8702 — Modern Texts)**

1. **Type: MCQ [Tests AO1]**
   * **Question:** A student writes: "Ishiguro presents Kathy growing up at Hailsham, becoming a carer, then a donor, and finally completing." For AO1, which AQA Level does this response sit at, and why?
   * **Options:** A) Level 6 — it is a critical, exploratory, conceptualised response to task and whole text, B) Level 5 — it is a thoughtful, developed response with apt references integrated into interpretation, C) Below the top bands — it narrates the plot across the whole text rather than conceptualising an idea, D) Level 6 — tracing events across the whole text is exactly what "response to whole text" rewards
   * **Correct:** C
   * **AO:** AO1
   * **Feedback:** ✓ Correct. AQA Level 6 AO1 is a "critical, exploratory, conceptualised response to task and whole text." Tracing Kathy's path from Hailsham to completion is plot narration, not a concept. To climb, the student must treat the novel as a vehicle for an idea — Ishiguro using the clones' passivity to interrogate mortality and complicity — not recount a life.
   * **Why A:** The conceptualised, critical argument the top band demands is absent — this narrates a life-course, it does not argue an idea.
   * **Why B:** A thoughtful, developed response with apt references needs both development and quotation, and this offers neither.
   * **Why D:** "Whole text" means arguing an idea across the novel, not listing the sequence of events that happen in it.
