# Mark Scheme Assessment Bank — Edexcel IGCSE Anthology Poetry (Language Spec A 4EA1)

Deterministic, code-scored MARK-SCHEME-LITERACY assessment bank (parsed by `SWML_Quiz_Bank::pick_session_msa`).
Examiner-level — harder and more precise than the Mark Scheme Quiz drill. Every question makes the
student JUDGE authentic anthology-poetry writing against the EXACT Edexcel IGCSE Spec A LANGUAGE (4EA1)
Level descriptors, and forces them to USE the mark scheme's own vocabulary rather than a simplified
paraphrase. Keys and feedback live server-side and are stripped before questions reach the client.
The AI is never the scorekeeper.

AOs are tagged per question for stratified random selection. On this Language specification the reading
objectives are AO1 (read and understand — retrieval and comprehension, Questions 1-3), AO2 (analyse
language and structure — the single-text 20-mark analysis) and AO3 (compare texts — the 20-mark
comparison). NOTE: on Spec A LANGUAGE, AO4 is imaginative WRITING and AO5 is technical accuracy —
context is NOT an assessment objective here (that is the Literature specification, where AO4 means
context). Question types: MCQ · Select All · Fill · Ranking.

Edexcel-IGCSE-exclusive: this bank serves ONLY Edexcel IGCSE Spec A (4EA1) anthology poetry, so it is a
single complete section by design — no other board uses these descriptors or this AO numbering.

The five anthology poems used here: "Disabled" (Wilfred Owen), "Out, Out—" (Robert Frost),
"An Unknown Girl" (Moniza Alvi), "The Bright Lights of Sarajevo" (Tony Harrison), "Still I Rise" (Maya Angelou).

### **SECTION A: EDEXCEL IGCSE SPEC A (4EA1 — Anthology Poetry)**

1. **Type: MCQ [Tests AO2]**
   * **Question:** A student writes: "Owen uses the metaphor 'threw away his knees'. This is a metaphor. It tells us the soldier lost his legs in the war." On the Edexcel IGCSE Spec A AO2 ladder, which Level does this reach, and what is its ceiling?
   * **Options:** A) Level 5 — it analyses perceptively, exploring the method's effect in detail, B) Level 4 — it explores the effect of the method thoroughly, C) Level 1 — it identifies a method but only restates the literal meaning, offering no comment on effect, D) Level 3 — it explains clearly how the method shapes the reader's response
   * **Correct:** C
   * **AO:** AO2
   * **Feedback:** ✓ Correct. The Spec A AO2 ladder runs identifies → comments → explains → explores → analyses perceptively. Naming the metaphor and paraphrasing its literal sense is Level 1 "identifies": a feature is spotted, but no effect is commented on. To climb, the writing must comment on, then explain, then explore how the method works on the reader.
   * **Why A:** Perceptive, detailed analysis (Level 5) explores layered effects, and none is offered here.
   * **Why B:** Thorough exploration (Level 4) needs the effect worked through; the effect is not even named.
   * **Why D:** Clear explanation (Level 3) requires the effect explained, not the literal meaning restated.

3. **Type: MCQ [Tests AO2]**
   * **Question:** One response explains how Frost's personified saw "snarled and rattled" makes it seem alive. Another reads the same personification as a sustained pattern that blurs machine and beast, so the accident in "Out, Out—" feels both mechanical and predatory, exploring several effects. Which single move lifts the second to Level 5?
   * **Options:** A) It quotes more lines from the poem to widen the evidence base, B) It moves from explaining one effect to a perceptive, detailed analysis that explores several effects of the method, C) It names additional techniques found elsewhere in the poem, D) It develops the point across a longer paragraph
   * **Correct:** B
   * **AO:** AO2
   * **Feedback:** ✓ Correct. The Spec A AO2 shift from Level 3 "explains" to Level 5 "analyses perceptively" is the move from one stated effect to a detailed, insightful reading that explores several. Reading the personification as a sustained machine-and-beast pattern is that perceptive move; length, quote-count and technique-listing do not raise the Level.
   * **Why A:** Quotation quantity is not a band criterion on this ladder.
   * **Why C:** Listing more techniques is identification, the Level 1 register.
   * **Why D:** Paragraph length is not a Level descriptor.

4. **Type: Ranking [Tests AO2]**
   * **Question:** Rank these four comments on Angelou's simile "like dust, I'll rise" and the refrain in "Still I Rise" from WEAKEST to STRONGEST by Edexcel IGCSE Spec A AO2 band (type the letters in order, weakest first).
   * **Options:** A) "Angelou's simile analyses how the poem transmutes an image of the trodden-down and worthless into buoyant inevitability, so each return of 'I rise' re-enacts a rising the oppressor cannot prevent.", B) "Angelou uses the simile 'like dust, I'll rise' to make the speaker sound confident.", C) "Angelou's simile 'like dust, I'll rise' clearly explains that although dust is trodden underfoot it still lifts, showing the speaker's refusal to stay down.", D) "Angelou explores the 'like dust' image and the repeated 'I rise' together, tracing in detail how each return of the refrain rebuilds the speaker's defiance."
   * **Correct:** B, C, D, A
   * **AO:** AO2
   * **Feedback:** ✓ Correct. Each rung is one Spec A AO2 band higher. The comment naming one simple effect (confident) is Level 2 "comments". The clear explanation of the trodden-yet-rising image is Level 3 "explains". The thorough exploration built across the poem is Level 4 "explores". The perceptive, detailed analysis reading the refrain as a re-enacted rising is Level 5 "analyses perceptively". The ladder is comment → explain → explore → analyse perceptively.
   * **WhyWrong:** Weakest to strongest runs from a simple comment on one effect, to a clear explanation, to a thorough exploration, to a perceptive analysis of how the refrain enacts the rising. The top band is insight, not more quotation.

5. **Type: Select All [Tests AO2]**
   * **Question:** Select ALL statements that are true of an Edexcel IGCSE Spec A Level 5 AO2 response on a poem, and none that are not.
   * **Options:** A) It moves beyond identifying a method to a perceptive, detailed analysis of how language and structure create meaning, B) It explores several effects a method has on the reader rather than stating a single fixed effect, C) It names as many techniques as possible to demonstrate range, D) It reads language and structure together — for instance, how Alvi's free-verse lines and repetition enact the same longing in "An Unknown Girl"
   * **Correct:** A, B, D
   * **AO:** AO2
   * **Feedback:** ✓ Correct. Level 5 "analyses perceptively" is perceptive, detailed analysis that explores layered effects and reads language with structure.    * **Why C:** Naming many techniques is identification, not perceptive analysis; the top band rewards insight into effect, not quantity.

6. **Type: MCQ [Tests AO2]**
   * **Question:** On Question 4 (single-text analysis, 20 marks), which comment on Harrison's rhyming couplets in "The Bright Lights of Sarajevo" reaches Level 5 "analyses perceptively" rather than Level 1 "identifies"?
   * **Options:** A) "Harrison writes the poem in rhyming couplets.", B) "Harrison uses rhyming couplets, which is a structural technique.", C) "Harrison's insistent couplets — pairing 'pass' with 'gas', 'prams' with 'grams' — impose an ordered music on scenes of shelling and queues, so the reader feels how precariously the young couple's tenderness is held together against the disorder of war.", D) "Harrison uses rhyming couplets to make the poem sound nice."
   * **Correct:** C
   * **AO:** AO2
   * **Feedback:** ✓ Correct. Level 5 offers perceptive, detailed analysis of how structure makes meaning: the ordered couplets set against wartime disorder, with the effect on the reader explored. Merely stating the form, labelling it a "technique", or asserting it "sounds nice" stays at Level 1 "identifies" or Level 2 "comments".
   * **Why A:** Stating the form is bare identification, Level 1.
   * **Why B:** Labelling it "a structural technique" still only identifies; no effect is analysed.
   * **Why D:** "Sounds nice" is an unfocused comment, not a perceptive analysis of structure and effect.

8. **Type: MCQ [Tests AO2]**
   * **Question:** A response notes that Owen's "Disabled" keeps swinging between "In the old times" and "Now". For Level 5 AO2 analysis of STRUCTURE, what must the response then do with that observation?
   * **Options:** A) Simply list every place the tense changes in the poem, B) Analyse perceptively how the past-present structure enacts the soldier's severed life — the vivid remembered youth set against the bleak dependent present — so the reader feels the wholeness the war destroyed, C) Explain that the poem is quite sad because the soldier is injured, D) Count how many stanzas the poem has
   * **Correct:** B
   * **AO:** AO2
   * **Feedback:** ✓ Correct. Structure earns Level 5 when its effect is analysed perceptively: the oscillation between past and present staged so the reader feels the rupture between the soldier's remembered youth and his diminished present. Listing shifts, a general emotional comment, or counting stanzas does not analyse the structure's effect.
   * **Why A:** A list of shifts is identification (Level 1), not analysis of their effect.
   * **Why C:** A general "sad" comment does not explain, let alone analyse, the structure.
   * **Why D:** Counting stanzas describes the form; it does not analyse how structure makes meaning.

11. **Type: MCQ [Tests AO1]**

   * **Correct:** B

   * **Feedback:** ✓ Correct. AO1 rewards accurate reading and understanding: retrieving precisely what the soldier has lost, anchored to the text. A general emotional reaction, a language analysis, or a structural point (both AO2) do not answer the retrieval-and-understanding demand.

   * **Correct:** D
   * **AO:** AO3
