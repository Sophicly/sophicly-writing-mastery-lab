# Marking Fairness — Universal (every board, every paper)

**Version:** 1.1.0 (Rule 5 + the bonus standard — v7.20.630, 2026-09-22)
**Scope:** EVERY assessment — Language + Literature, GCSE + IGCSE + N5/Higher, all boards.
**Loaded by:** every board manifest's `assessment.always` (resolved via shared fallback).
**Relationship to other modules:** element ROWS, mark VALUES and penalty CODES live in the paper's `protocol-a-assessment.md`. This module governs HOW those marks are awarded — fairly and consistently. Where a paper module and these fairness rules conflict, **these rules win**.

These rules exist for a measured reason: the *same* student response was marked **3.25/4 one run and 1.75/4 the next** — identical work, a 10-mark swing across the paper. The drift came from improvising the element list, double-counting the same fault, and zeroing analysis that was genuinely present. Pin the shape; credit what's there; charge each fault once; make the number match your words.

---

## Rule 1 — Pinned element table (do not improvise the shape)

Mark using the element rows + worths **exactly** as the paper's `protocol-a-assessment.md` lists them for this question / paragraph. Do **not** add a row, drop a row, rename, reorder, or merge rows. Score **every** listed element, **every** paragraph, **every** time — even if you score it 0. The table's shape is fixed by the protocol, never by your judgement in the moment. (A row scored 0 with a reason teaches; an omitted row is invisible drift.)

## Rule 2 — Award what is present (examiners credit the work that is there)

A real examiner awards the marks the response earns; they do not zero a whole element because the response also has a flaw. If analysis is genuinely present but (a) targets the wrong AO / focus (e.g. language analysis in a structure question), or (b) uses imprecise terminology, then **award the element the marks its substance earns**, and apply **ONE** small penalty (−0.5) for the drift / terminology. **Never withhold all the strength credit** for a paragraph that contains real, creditable analysis. Misdirected good analysis is partially creditable, not worthless.

## Rule 3 — No double jeopardy (charge each fault once)

A single fault may reduce the mark **once**. If a fault is already reflected in a reduced or withheld **element score**, it must **not** also be taken as a **penalty** deduction — and vice-versa. Penalties are only for faults **not already captured** in the element scoring. You cannot deduct for something that was never awarded.

## Rule 4 — Consistency gate (the number must match your prose)

Before you output a paragraph total, check it against your own written assessment. If your prose calls the work "perceptive", "sophisticated", "top-band", "a genuine strength", or "Grade 8/9", the element scores **must** reflect that — a paragraph you praised cannot total near-zero. If the number and the words disagree, **re-mark** until they agree. The written feedback and the score are one judgement, not two.

## Rule 5 — The final 0.25 of every criterion is for perceptiveness

Every criterion's **last 0.25** is reserved for work that is **perceptive**: insightful, beyond the obvious, **convincing**, and **traceable to the words on the page**. It is the board's own top step — *"Clear, relevant"* becomes *"Perceptive, detailed"*; *"convincing… judicious"*. A criterion that is met **clearly and accurately but not perceptively scores at most its worth minus 0.25** (a 0.5 criterion → 0.25; a 1.0 criterion → 0.75; a 1.5 criterion → 1.25). Below that quarter, mark the criterion exactly as its row describes. **Never award the quarter for a reading the text cannot support** — an idea "thrown in" that the quoted words do not carry is unsupported, and stays at the clear mark. **Say so in the Why** (*"clear; not yet perceptive"* · *"perceptive — 'redemption' as being saved from evil"*), so the student always knows which quarter they missed and what would have earned it.

Where a criterion's name already carries the word (*"Perceptive inferences"*, *"Judicious, integrated quotes"*, *"Conceptual topic sentence"*), the name stays and the rule reads the same way: the clear version earns everything but the last quarter; the perceptive version earns it all.

**Rule 5 does not apply where there are no criteria:** retrieval / right-or-wrong questions (Q1 on every language paper, per-statement marks); extended writing marked as a whole piece by band (Section B / Q5, AO5 + AO6); any separate technical-accuracy mark (AO4 SPaG, IGCSE AO5); quizzes; and penalty rows.

## Bonus elements

A paper's protocol may label an element **BONUS** (for example, *interrelationship of techniques* — a sophistication examiners reward but do not require). A bonus element:

- is **not** part of the base denominator — the paragraph maximum comes from the non-bonus elements;
- **adds** its worth on top when present, **capped** at the paragraph maximum;
- is **never** penalised, deducted, or listed as a weakness when absent — it can only ever help.

Award bonus marks for genuine quality; never require them, never punish their absence.

**The standard for a bonus is the top of the ladder (Neil, 2026-09-22).** A bonus is an examiner's reward for sophistication, so the whole of it is a Level-4 award: award the interplay bonus **only** when the analysis of how the techniques work together is **convincing and perceptive** — the relationship is real in the quoted words, it is explained (reinforce / tension / amplify), and it goes beyond naming two techniques side by side. Two techniques listed, or a relationship the text does not support, earns no bonus and no comment.
