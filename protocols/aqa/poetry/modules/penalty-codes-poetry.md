### **1.D Penalty Codes for Poetry Comparison Assessment**

Instructions: Apply penalties using codes for consistency. Show before→after fixes when deducting marks. **Maximum deductions (COUNT, not a fixed total): Intro (2), Body (3), Conclusion (2).** The deduction TOTAL is simply the sum of the codes you actually apply (each carries its own −value); there is no fixed "= −X total". Applying 0, 1 or 2 penalties (3 for body paragraphs) are ALL valid outcomes — never invent a fault to fill a slot.

**\[AI\_INTERNAL\] UNIVERSAL REGISTRY (shared across every WML paper — one code, one meaning, everywhere).** These are the SAME codes AQA Language and Literature use; the platform's penalty machinery (the F1/T1 verb-tier stripping, the penalty-integrity auditor) recognises them. NEVER emit a legacy poetry-only code (BP-*, INT-*, CON-*, W1) — those are retired; use the universal code or the comparative extension below.

#### **Core Writing Penalties (All Sections):**

H1 – Hanging/incorrectly punctuated quotes (-0.5) Detection: Quote dropped without integration or incorrect punctuation Fix: "the guns" → the poet's fixation surfaces in the repeated "guns"

P1 – Comma splice/run-on/fused sentence (-0.5) Detection: Independent clauses joined incorrectly Fix: Add coordinator (FANBOYS), use full stop/semicolon, or subordinate

C1 – Clarity/flow lapse creating ambiguity (-0.5) Detection: Muddled cause→effect, vague pronouns, logical gaps Fix: Clarify referents, tighten verbs, add sequence markers

T2 – Lacks transitional phrases/discourse markers (-0.5) Detection: Missing connectives between concepts Fix: Add Furthermore, Consequently, Similarly, By contrast

F1 – Weak analytical verb (-0.5 per instance) Detection: any banned/weak-tier verb ("shows," "tells us," "is about," "acts as," "illustrates," "aims to/seems to [verb]," uses/has/says/makes) doing the analytical work Upgrade: conveys, constructs, positions, depicts, portrays, emphasizes, highlights, reveals, suggests, evokes, underscores, reinforces, critiques, challenges, exposes, examines

S1 – Weak/repetitive sentence starters (-0.5 per instance) Detection: the SAME starter word ("The", "This" or "These") opening two or more sentences in one paragraph. Allowance: one sentence starting with "The", one with "This" and one with "These" per paragraph is permitted — never penalise the first instance of each word. Upgrade: discourse markers, prepositional phrases, adverbial openers

S2 – Underdeveloped sentences (less than 2 lines) (-0.5) Detection: Sentences lacking detail (except hooks/topic sentences) Fix: Expand with analysis, examples, developed explanation

R1 – Unstrategic repetition of words (-0.5) Detection: Same words used without rhetorical purpose Fix: Use synonyms or pronouns strategically

G1 – SPaG errors undermining clarity (-0.5) Detection: Grammar/spelling affecting meaning Fix: Correct errors that create ambiguity

#### **Analysis Penalties (poetry uses these where the older BP-*/INT-*/CON- codes used to sit):**

Q1 – Quote selection issues (-0.5) Detection: Quotes clustered/not strategic/don't support the point (replaces BP-EV) Fix: Select quotes that demonstrate the comparative concept

I1 – Imprecise/underdeveloped interpretation (-0.5) Detection: Surface-level close analysis, no word/sound zoom (replaces BP-CA) Fix: Deepen with specific word-level evidence and precise interpretation

E1 – Lacks evaluative/tentative language (-0.5) Detection: Overly declarative; no evaluative judgement (replaces CON-EV) Fix: Add "perhaps," "suggests," "arguably"; state which poem is more effective and why

E2 – Underdeveloped effect on reader (Body only) (-0.5) Detection: Reader-effect less than 2 sentences, or effect not differentiated per poet (replaces BP-EF) Fix: Expand each poet's distinct emotional/intellectual impact

P2 – Lacks perceptive insight (-0.5) Detection: Missing deeper analytical layer; conclusion offers no new insight (replaces CON-NI) Fix: Move beyond the obvious to explore implications across both poems

X1 – Irrelevant/unexplained context (-0.5) Detection: Context doesn't support the argument (replaces context misuse) Fix: Ensure each poet's context drives interpretation causally

STR2 – TTECEA order violation (Body only) (-0.5) Detection: All elements present but wrong sequence, e.g. Effects before Close Analysis (replaces BP-OR). **Note:** content marks preserved, structure mark deducted. Exception: family-first (first-ever) assessment only (baseline)

#### **Comparative-Specific Penalties (Poetry extension — no single-text equivalent):**

CMP1 – No sustained comparison / poems treated separately (-0.5) Detection: the section analyses one poem then the other in blocks, or the topic sentence/thesis is not comparative (replaces INT-NC, BP-NC, CON-NC, INT-TH, CON-TH, INT-CT). This is the defining comparison fault. Fix: interleave BOTH poems in every analytical move — "Where Duffy foregrounds X, Armitage instead …" — and make the topic sentence a claim about BOTH poets together.

CMP2 – Wrong focus for the paragraph (Body only) (-0.5) Detection: the paragraph analyses the wrong dimension for its slot — structure/language in the FORM paragraph, form/language in the STRUCTURE paragraph, etc. (replaces BP-WF) Fix: refocus Body 1 on FORM (genre/type), Body 2 on STRUCTURE (metre/rhyme/enjambment), Body 3 on LANGUAGE (imagery/diction/sound).
